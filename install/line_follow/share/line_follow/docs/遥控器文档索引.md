# 遥控器文档索引

当前工程里和遥控器相关的调试文档分成两类，请按实际使用场景选择。

## 1. 手动遥控版

适用场景：

- 只需要遥控器手动控制小车前进和后退
- 不需要长按切换巡线模式
- 遥控器输入直接控制 `/motor_speed_cmd`

推荐入口：

```bash
ros2 run line_follow remote_relay_drive_node
```

对应文档：

[遥控器部署调试指南.md](/home/yunbo/rdk_backup/dev_ws/src/originbot/Line_follow/Markdown/遥控器部署调试指南.md)

核心行为：

- 前进脚 `32` 控制前进
- 后退脚 `33` 控制后退
- 松开后停车
- 两个键同时按下时停车

## 2. 长按巡线模式版

适用场景：

- 需要“长按前进进入前进模式”
- 需要“长按后退进入巡线模式”
- 松开按键后立即停车

推荐入口：

```bash
ros2 run line_follow remote_long_press_start_line_follow_node
```

对应文档：

[长按遥控器巡线调试指南.md](/home/yunbo/rdk_backup/dev_ws/src/originbot/Line_follow/Markdown/长按遥控器巡线调试指南.md)

核心行为：

- 长按前进脚 `32` 进入手动前进模式
- 松开前进脚停车
- 长按后退脚 `33` 打开已经常驻的巡线输出
- 松开后退脚关闭巡线输出并停车

## 3. 如何选择

如果你现在只是想让遥控器直接控制车体前进后退，使用：

- `ros2 run line_follow remote_relay_drive_node`

如果你现在想让遥控器承担“模式切换”，也就是：

- 长按前进时手动前进
- 长按后退时自动巡线

那就使用：

- `ros2 run line_follow remote_long_press_start_line_follow_node`

## 4. 注意事项

- 不要同时运行这两个脚本
- 两个脚本都会涉及 `/motor_speed_cmd` 控制链路
- 同时运行会导致控制逻辑打架
