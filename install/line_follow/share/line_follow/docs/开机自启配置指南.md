# 开机自启配置指南

本文档按当前程序状态整理板端 `systemd` 自启方式。

## 1. 当前唯一推荐入口

当前推荐只保留一套联合入口：

```bash
ros2 launch line_follow joystick_remote_hybrid.launch.py \
  device:=/dev/video0 \
  enable_websocket:=true \
  enable_dashboard:=true
```

这条入口会统一启动：

- 相机链路
- `/image -> /hbmem_img` 解码和共享内存链路
- 巡线核心节点
- 电机驱动节点
- 长按遥控节点
- 摇杆节点
- Web 页面和 dashboard

## 2. 当前推荐服务形态

当前只推荐保留：

- `line-follow-hybrid.service`

下面这些旧服务不应再与联合服务并行运行：

- `line-follow-remote.service`
- `line-follow-stack.service`
- `line-follow-web.service`

如果它们和 `line-follow-hybrid.service` 同时运行，最常见的问题就是：

- 出现两个 `/line_follow_motor_model_node`
- 出现两套驱动节点
- 相机链路重复启动
- 串口和节点名冲突

## 3. 写启动脚本

在板端创建：

```bash
/userdata/dev_ws/start_line_follow_hybrid.sh
```

内容如下：

```bash
#!/usr/bin/env bash
set -e

cd /userdata/dev_ws
source /opt/ros/humble/setup.bash
source /userdata/dev_ws/install/setup.bash

exec ros2 launch line_follow joystick_remote_hybrid.launch.py \
  device:=/dev/video0 \
  enable_websocket:=true \
  enable_dashboard:=true
```

给执行权限：

```bash
chmod +x /userdata/dev_ws/start_line_follow_hybrid.sh
```

如果你不想开机带 Web，可改成：

```bash
enable_websocket:=false enable_dashboard:=false
```

## 4. 写 systemd 服务文件

在板端创建：

```bash
/etc/systemd/system/line-follow-hybrid.service
```

内容如下：

```ini
[Unit]
Description=Line Follow Hybrid Service
After=network.target
Wants=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/userdata/dev_ws
ExecStart=/userdata/dev_ws/start_line_follow_hybrid.sh
Restart=always
RestartSec=2
KillMode=control-group
TimeoutStopSec=10

[Install]
WantedBy=multi-user.target
```

## 5. 迁移到当前唯一服务

```bash
systemctl daemon-reload
systemctl disable --now line-follow-remote.service || true
systemctl disable --now line-follow-stack.service || true
systemctl disable --now line-follow-web.service || true
systemctl enable line-follow-hybrid.service
systemctl start line-follow-hybrid.service
```

如果你怀疑旧节点残留，再补一轮清理：

```bash
pkill -f line_follow || true
pkill -f joystick_drive_node || true
pkill -f remote_long_press_start_line_follow_node || true
pkill -f web_debug_dashboard_node || true
sleep 2
systemctl restart line-follow-hybrid.service
```

## 6. 查看状态和日志

```bash
systemctl status line-follow-hybrid.service
journalctl -u line-follow-hybrid.service -f
```

确认旧服务没有再并行运行：

```bash
systemctl status line-follow-remote.service line-follow-stack.service line-follow-web.service --no-pager
```

## 7. 验证是否只有一套节点

```bash
source /opt/ros/humble/setup.bash
source /userdata/dev_ws/install/setup.bash
ros2 node list | sort | uniq -c | grep -E "line_follow|joystick|remote"
ros2 node list | grep line_follow_motor_model_node | wc -l
```

`/line_follow_motor_model_node` 的数量应该是 `1`。

## 8. 常见问题

### 8.1 出现两个 `/line_follow_motor_model_node`

说明旧服务没停干净，或手工又起了一套 launch。

处理：

```bash
systemctl stop line-follow-remote.service || true
systemctl stop line-follow-stack.service || true
systemctl stop line-follow-web.service || true
systemctl stop line-follow-hybrid.service || true
pkill -f line_follow || true
sleep 2
systemctl start line-follow-hybrid.service
```

### 8.2 Web 页面打不开

先检查启动脚本里是否带了：

```bash
enable_websocket:=true enable_dashboard:=true
```

再看：

```bash
journalctl -u line-follow-hybrid.service -n 100 --no-pager
```

### 8.3 长按后退不能进入巡线

重点排查：

- `/hbmem_img` 是否存在
- `/line_follow/line_detected` 是否有输出
- `/line_follow/set_enabled` 是否被发布
- 是否误起了两套模型节点
