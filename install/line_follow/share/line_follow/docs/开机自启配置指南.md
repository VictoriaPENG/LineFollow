# 开机自启配置指南

本文档说明如何在开发板上把当前程序设置为开机自动运行。

推荐使用：

- `systemd`

不推荐使用：

- `rc.local`
- 临时手工后台命令

原因很简单：

- `systemd` 更稳定
- 支持自动重启
- 方便查看状态和日志
- 更适合 ROS 程序长期运行

## 1. 当前可自启的两种模式

当前工程里建议开机自启的遥控器相关程序有两种：

### 1.1 手动遥控版

适用场景：

- 开机后只需要遥控器手动控制前进和后退

入口命令：

```bash
ros2 run line_follow remote_relay_drive_node
```

注意：

- 这个节点只发布 `/motor_speed_cmd`
- 还需要单独启动电机驱动节点

### 1.2 长按巡线模式版

适用场景：

- 开机后由遥控器长按切换模式
- 长按前进进入手动前进模式
- 长按后退进入巡线模式

入口命令：

```bash
ros2 run line_follow remote_long_press_start_line_follow_node
```

注意：

- 这个节点会自己拉起 `motor_driver_control_node`
- 长按后退进入巡线时，会自动执行：

```bash
ros2 launch line_follow line_follow_system.launch.py start_driver:=false
```

如果你当前用的是长按模式，推荐自启这个版本。

## 2. 自启前准备

先确认程序已经能在板端手工正常运行。

板端执行：

```bash
cd /userdata/dev_ws
source /opt/ros/humble/setup.bash
source /userdata/dev_ws/install/setup.bash
```

确认以下命令至少有一条能正常运行：

```bash
ros2 run line_follow remote_relay_drive_node
ros2 run line_follow remote_long_press_start_line_follow_node
```

如果手工运行都不正常，不要先做开机自启，先解决程序本身问题。

## 3. 推荐做法：systemd 服务

建议拆成两步：

1. 先写启动脚本
2. 再写 systemd service

## 4. 方案 A：长按巡线模式开机自启

这是目前更推荐的方式。

### 4.1 写启动脚本

在板端创建：

```bash
/userdata/dev_ws/start_remote_long_press.sh
```

内容如下：

```bash
#!/usr/bin/env bash
set -e

cd /userdata/dev_ws
source /opt/ros/humble/setup.bash
source /userdata/dev_ws/install/setup.bash

exec ros2 run line_follow remote_long_press_start_line_follow_node
```

给执行权限：

```bash
chmod +x /userdata/dev_ws/start_remote_long_press.sh
```

### 4.2 写 systemd 服务文件

在板端创建：

```bash
/etc/systemd/system/line-follow-remote.service
```

内容如下：

```ini
[Unit]
Description=Line Follow Remote Long Press Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/userdata/dev_ws
ExecStart=/userdata/dev_ws/start_remote_long_press.sh
Restart=always
RestartSec=2

[Install]
WantedBy=multi-user.target
```

### 4.3 启用并启动服务

```bash
systemctl daemon-reload
systemctl enable line-follow-remote.service
systemctl start line-follow-remote.service
```

### 4.4 查看状态和日志

```bash
systemctl status line-follow-remote.service
journalctl -u line-follow-remote.service -f
```

## 5. 方案 B：手动遥控版开机自启

如果你只想开机后直接让遥控器控制前进/后退，可以用这个方案。

注意：

- 这个方案需要同时启动两个 ROS 程序：
  - `motor_driver_control_node`
  - `remote_relay_drive_node`

最简单稳定的方式是写一个统一启动脚本。

### 5.1 写启动脚本

在板端创建：

```bash
/userdata/dev_ws/start_remote_manual.sh
```

内容如下：

```bash
#!/usr/bin/env bash
set -e

cd /userdata/dev_ws
source /opt/ros/humble/setup.bash
source /userdata/dev_ws/install/setup.bash

ros2 run line_follow motor_driver_control_node &
sleep 2

exec ros2 run line_follow remote_relay_drive_node
```

给执行权限：

```bash
chmod +x /userdata/dev_ws/start_remote_manual.sh
```

### 5.2 写 systemd 服务文件

在板端创建：

```bash
/etc/systemd/system/line-follow-remote-manual.service
```

内容如下：

```ini
[Unit]
Description=Line Follow Remote Manual Drive Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/userdata/dev_ws
ExecStart=/userdata/dev_ws/start_remote_manual.sh
Restart=always
RestartSec=2

[Install]
WantedBy=multi-user.target
```

### 5.3 启用并启动服务

```bash
systemctl daemon-reload
systemctl enable line-follow-remote-manual.service
systemctl start line-follow-remote-manual.service
```

### 5.4 查看状态和日志

```bash
systemctl status line-follow-remote-manual.service
journalctl -u line-follow-remote-manual.service -f
```

## 6. 如何停用自启

如果要关闭某个服务的开机自启：

```bash
systemctl disable line-follow-remote.service
systemctl disable line-follow-remote-manual.service
```

如果要立即停止服务：

```bash
systemctl stop line-follow-remote.service
systemctl stop line-follow-remote-manual.service
```

如果修改过 service 文件，记得重新加载：

```bash
systemctl daemon-reload
```

## 7. 常见问题

### 7.1 开机后服务启动失败

先看状态：

```bash
systemctl status line-follow-remote.service
```

或者：

```bash
systemctl status line-follow-remote-manual.service
```

再看日志：

```bash
journalctl -u line-follow-remote.service -f
```

常见原因：

1. 没有正确 `source /opt/ros/humble/setup.bash`
2. 没有正确 `source /userdata/dev_ws/install/setup.bash`
3. 程序本身手工运行就失败
4. GPIO 模块没装好
5. 串口设备名不对

### 7.2 修改代码后开机服务还是旧行为

先重新编译：

```bash
cd /userdata/dev_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select line_follow --executor sequential --parallel-workers 1
source /userdata/dev_ws/install/setup.bash
```

再重启服务：

```bash
systemctl restart line-follow-remote.service
```

或：

```bash
systemctl restart line-follow-remote-manual.service
```

### 7.3 两种模式不要同时自启

不要同时启用下面两个服务：

- `line-follow-remote.service`
- `line-follow-remote-manual.service`

原因：

- 两套模式都会涉及 `/motor_speed_cmd`
- 同时启用会导致控制逻辑冲突

## 8. 推荐结论

如果你当前主用的是“长按前进/长按后退切模式”，推荐启用：

```bash
line-follow-remote.service
```

如果你只是要最简单的遥控器手动前进后退，启用：

```bash
line-follow-remote-manual.service
```
