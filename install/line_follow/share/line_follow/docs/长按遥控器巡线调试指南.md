# 长按遥控器巡线调试指南

本文档对应当前长按模式控制节点：

```bash
ros2 run line_follow remote_long_press_start_line_follow_node
```

当前实现已经改为：

- 节点启动时先常驻拉起整套巡线系统
- 默认让巡线速度输出处于关闭状态
- 长按前进键进入手动前进模式
- 长按后退键打开巡线输出进入自动巡线模式
- 松开任意按键后立即停车，并关闭巡线输出

## 1. 当前行为

主入口：

```bash
ros2 run line_follow remote_long_press_start_line_follow_node
```

兼容入口：

```bash
python3 tools/remote_long_press_start_line_follow.py
```

固定行为：

- 监听 40Pin 物理针脚 `32` 和 `33`
- `32` 为前进通道
- `33` 为后退通道
- 低电平有效
- 长按阈值默认 `1.5` 秒
- 松开按键后立即停车

模式说明：

- 长按前进脚 `32`
  - 关闭巡线输出
  - 直接向 `/motor_speed_cmd` 持续发布前进速度
- 松开前进脚
  - 立即发布零速
- 长按后退脚 `33`
  - 不再临时启动 launch
  - 仅把 `/line_follow_motor_model_node` 的 `enabled` 置为 `true`
  - 让已经常驻的巡线系统开始向 `/motor_speed_cmd` 发布巡线速度
- 松开后退脚
  - 将 `enabled` 置回 `false`
  - 发布零速
- 两个按键同时按下
  - 不进入任何模式，直接保持停止

## 2. 当前进程关系

这个脚本启动后会先拉起：

```bash
ros2 launch line_follow line_follow_system.launch.py line_follow_enabled:=false
```

也就是说，以下节点会先常驻起来：

- `line_follow_angle_node`
- `line_follow_motor_model_node`
- `motor_driver_control_node`

其中巡线运动模型节点新增了运行时参数：

```bash
/line_follow_motor_model_node enabled
```

这个参数用于控制是否真正输出巡线速度。

## 5. 推荐调试顺序

### 5.1 先确认系统已常驻但默认不跑车

启动长按节点后检查：

```bash
ros2 param get /line_follow_motor_model_node enabled
ros2 topic echo /motor_speed_cmd
```

预期：

- `enabled` 默认是 `False`
- 不按遥控器时应保持零速

### 5.2 再确认长按前进模式

长按前进键超过 `1.5` 秒后检查：

```bash
ros2 param get /line_follow_motor_model_node enabled
ros2 topic echo /motor_speed_cmd
```

预期：

- `enabled` 保持 `False`
- `/motor_speed_cmd` 持续输出手动前进命令
- 默认前进速度为 `[-300.0, 300.0]`

松开后应回到：

```bash
[0.0, 0.0]
```

### 5.3 最后确认长按后退巡线模式

长按后退键超过 `1.5` 秒后检查：

```bash
ros2 param get /line_follow_motor_model_node enabled
ros2 topic echo /motor_speed_cmd
```

预期：

- `enabled` 变为 `True`
- 由巡线模型节点接管 `/motor_speed_cmd`
- 小车进入自动巡线

松开后预期：

- `enabled` 回到 `False`
- `/motor_speed_cmd` 回到零速

## 7. 当前关键参数

长按节点默认参数：

- `forward_pin = 32`
- `reverse_pin = 33`
- `hold_seconds = 1.5`
- `forward_left_rpm = -300.0`
- `forward_right_rpm = 300.0`
- `speed_topic = /motor_speed_cmd`
- `line_follow_node_name = /line_follow_motor_model_node`
- `launch_command = ros2 launch line_follow line_follow_system.launch.py line_follow_enabled:=false`

整机 launch 新增参数：

- `line_follow_enabled`
  - 默认 `true`
  - 长按模式场景下建议由长按节点以 `false` 启动，再通过运行时参数切换

运动模型节点新增运行时参数：

- `enabled`
  - `true` 时允许输出巡线速度
  - `false` 时立即发零速并停止继续输出

## 8. 临时调参示例

把长按阈值调短到 1 秒：

```bash
ros2 run line_follow remote_long_press_start_line_follow_node --ros-args -p hold_seconds:=1.0
```

把手动前进速度调小：

```bash
ros2 run line_follow remote_long_press_start_line_follow_node --ros-args \
  -p forward_left_rpm:=-200.0 \
  -p forward_right_rpm:=200.0
```

手工切换巡线使能：

```bash
ros2 param set /line_follow_motor_model_node enabled true
ros2 param set /line_follow_motor_model_node enabled false
```

## 9. 常见问题

### 9.1 `line_follow_angle_node` 找不到

先检查是不是没有启动新的长按节点，或者工作区没重新编译：

```bash
ros2 node list | grep line_follow
```

现在正常情况下，长按节点启动后视觉、模型、驱动节点都应该已经常驻。

### 9.2 长按后退没有进入巡线模式

先检查：

```bash
ros2 param get /line_follow_motor_model_node enabled
```

如果没有从 `False` 变成 `True`，再看长按节点终端日志里是否提示：

- `parameter service not ready`
- `line-follow enable switch rejected`

### 9.3 手动前进和巡线命令打架

当前版本已经通过 `enabled` 开关避免这个问题：

- 手动前进时会先关闭巡线输出
- 自动巡线时由模型节点接管速度输出

如果仍然打架，优先检查是否还有别的节点也在往 `/motor_speed_cmd` 发命令。
