## 3. 运行环境

- ROS 发行版：ROS 2 Humble
- 仿真器：Gazebo Classic（`gazebo_ros`）
- ROS 包：`line_follow`
- 当前模型边界：通过 `gazebo_msgs/srv/SetEntityState` 更新车体位姿，不代表完整履带动力学。

## 4. World

- World 文件：`worlds/line_follow_track.world`
- SDF 版本：`1.6`
- World 名称：`line_follow_track`
- 场景：浅色地面、黑色引导线、直线接分段曲线
- Gazebo 状态插件：`libgazebo_ros_state.so`

## 5. 构建与启动命令

在 ROS 2 工作空间根目录执行：

```bash
source /opt/ros/humble/setup.bash
colcon build --packages-select line_follow
source install/setup.bash
```

基线启动命令：

```bash
ros2 launch line_follow gazebo_line_follow_sim.launch.py \
  x:=-1.5 \
  y:=0.0 \
  z:=0.0 \
  detection_method:=threshold \
  thresh:=120 \
  morph_ksize:=3 \
  margin:=80 \
  minpix:=20 \
  roi_bottom_offset_ratio:=0.0 \
  roi_height_ratio:=0.70 \
  roi_left_margin_ratio:=0.08 \
  roi_right_margin_ratio:=0.08 \
  base_search_half_width_ratio:=0.25 \
  base_motor_rpm:=450.0 \
  max_motor_rpm:=900.0 \
  max_delta_motor_rpm:=700.0 \
  max_motor_rpm_step_per_sec:=2500.0 \
  heading_gain:=20.0 \
  offset_gain_deg:=8.0 \
  angle_lowpass_alpha:=0.55 \
  angle_deadband_deg:=2.5 \
  angular_scale:=1.0 \
  start_dashboard:=true \
  dashboard_port:=8091
```

未在命令中显式列出的参数使用本记录第 7 节所列默认值及 `config/line_follow_params.yaml` 中的版本化配置。
