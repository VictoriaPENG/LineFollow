# 代码同步与编译指南

本文档按当前程序状态整理开发机到 RDK 板端的同步、编译和重启流程。

当前唯一推荐常驻服务是：

- `line-follow-hybrid.service`

它负责统一启动图像链路、巡线核心、驱动、长按遥控、摇杆以及 Web 页面。旧的 `line-follow-remote.service`、`line-follow-stack.service`、`line-follow-web.service` 不应再并行启动。

## 1. 快速同步、编译并重启

在开发机执行：

```bash
cd /home/yunbo/rdk_backup/dev_ws/src/originbot/Line_follow
./tools/sync_to_board.sh && ssh root@192.168.127.10 "\
  systemctl stop line-follow-hybrid.service || true && \
  cd /userdata/dev_ws && \
  rm -rf build/line_follow install/line_follow && \
  source /opt/ros/humble/setup.bash && \
  colcon build --packages-select line_follow && \
  source install/setup.bash && \
  pkill -f line_follow || true && \
  pkill -f joystick_drive_node || true && \
  pkill -f remote_long_press_start_line_follow_node || true && \
  pkill -f web_debug_dashboard_node || true && \
  sleep 2 && \
  systemctl start line-follow-hybrid.service"
  systemctl stop line-follow-hybrid.service
```

## 2. 分步操作

### 2.1 同步代码到板端

```bash
cd /home/yunbo/rdk_backup/dev_ws/src/originbot/Line_follow
./tools/sync_to_board.shsystemctl is-enabled line-follow-hybrid.service
```

### 2.2 停止所有旧服务和联合服务

```bash
ssh root@192.168.127.10 "systemctl stop line-follow-remote.service || true"
ssh root@192.168.127.10 "systemctl stop line-follow-stack.service || true"
ssh root@192.168.127.10 "systemctl stop line-follow-web.service || true"
ssh root@192.168.127.10 "systemctl stop line-follow-hybrid.service || true"
```

### 2.3 清理旧编译产物

```bash
ssh root@192.168.127.10 "cd /userdata/dev_ws && rm -rf build/line_follow install/line_follow"
```

### 2.4 重新编译

```bash
ssh root@192.168.127.10 " \
  cd /userdata/dev_ws && \
  source /opt/ros/humble/setup.bash && \
  colcon build --packages-select line_follow && \
  source install/setup.bash \
"
```

### 2.5 清残留节点

```bash
ssh root@192.168.127.10 "\
  pkill -f line_follow || true && \
  pkill -f joystick_drive_node || true && \
  pkill -f remote_long_press_start_line_follow_node || true && \
  pkill -f web_debug_dashboard_node || true && \
  sleep 2"
```

### 2.6 启动唯一联合服务

```bash
ssh root@192.168.127.10 "systemctl start line-follow-hybrid.service"
```

## 3. 验证部署成功

### 3.1 检查服务状态

```bash
ssh root@192.168.127.10 "systemctl status line-follow-hybrid.service"
```

### 3.2 确认旧服务没有并行运行

```bash
ssh root@192.168.127.10 "systemctl status line-follow-remote.service line-follow-stack.service line-follow-web.service --no-pager"
```

### 3.3 检查节点运行

```bash
ssh root@192.168.127.10 "source /opt/ros/humble/setup.bash && source /userdata/dev_ws/install/setup.bash && ros2 node list | grep -E 'line_follow|joystick|remote|web'"
```

### 3.4 检查没有重复模型节点

```bash
ssh root@192.168.127.10 "source /opt/ros/humble/setup.bash && source /userdata/dev_ws/install/setup.bash && ros2 node list | grep line_follow_motor_model_node | wc -l"
```

正确结果应该是 `1`。

### 3.5 查看日志

```bash
ssh root@192.168.127.10 "journalctl -u line-follow-hybrid.service -n 50 --no-pager"
```

## 4. 当前联合服务的实际入口

当前 `line-follow-hybrid.service` 应该跑：

```bash
ros2 launch line_follow joystick_remote_hybrid.launch.py \
  device:=/dev/video0 \
  enable_websocket:=true \
  enable_dashboard:=true
```

如果不需要 Web，可改成：

```bash
enable_websocket:=false enable_dashboard:=false
```

## 5. 常见问题

### 5.1 出现两个 `/line_follow_motor_model_node`

原因基本就是旧服务没停干净，或你手工还起过别的 launch。

处理：

```bash
ssh root@192.168.127.10 "systemctl stop line-follow-remote.service line-follow-stack.service line-follow-web.service line-follow-hybrid.service || true"
ssh root@192.168.127.10 "pkill -f line_follow || true"
ssh root@192.168.127.10 "sleep 2"
ssh root@192.168.127.10 "systemctl start line-follow-hybrid.service"
```

### 5.2 Web 页面打不开

先看联合服务启动命令里是否传了：

```bash
enable_websocket:=true enable_dashboard:=true
```

再看：

```bash
ssh root@192.168.127.10 "journalctl -u line-follow-hybrid.service -n 100 --no-pager"
```

### 5.3 摇杆能动，长按后退不进入巡线

重点排查：

- `/hbmem_img` 是否存在
- `/line_follow/line_detected` 是否有输出
- `/line_follow/set_enabled` 是否被长按节点发布
- `/line_follow_motor_model_node` 是否只有一套
