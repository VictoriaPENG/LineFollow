# 开发机保存网页调试图像

网页调试地址：

```text
http://192.168.127.10:8091/
```

在开发机上进入工程目录：

```bash
cd /home/yunbo/rdk_backup/dev_ws/src/originbot/Line_follow
```

保存当前网页中的四路图像：

```bash
python3 tools/save_web_debug_frames.py --host 192.168.127.10 --port 8091
```

默认保存目录：

```text
web_debug_frames/日期_时间/
```

默认会保存：

```text
source.jpg
detect.jpg
binary.jpg
curve.jpg
```

只保存原图和检测图：

```bash
python3 tools/save_web_debug_frames.py \
  --host 192.168.127.10 \
  --port 8091 \
  --streams source detect
```

连续保存 20 组，每 0.5 秒保存一次：

```bash
python3 tools/save_web_debug_frames.py \
  --host 192.168.127.10 \
  --port 8091 \
  --count 20 \
  --interval-sec 0.5
```

指定保存根目录：

```bash
python3 tools/save_web_debug_frames.py \
  --host 192.168.127.10 \
  --port 8091 \
  --out-dir /tmp/line_follow_web_frames
```

如果提示连接失败，先确认：

```bash
curl -I http://192.168.127.10:8091/
```

浏览器能打开网页，但脚本保存失败时，优先检查开发机和板端是否在同一网络、板端网页调试节点是否仍在运行。
