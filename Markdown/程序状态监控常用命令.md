# 程序状态监控常用命令

本文档按当前程序状态整理板端常用监控命令。

当前唯一推荐常驻服务是：

1. `line-follow-hybrid.service`
   入口是 `ros2 launch line_follow joystick_remote_hybrid.launch.py`
   它会统一启动：
   - 相机链路
   - `/image -> /hbmem_img` 解码和共享内存链路
   - 巡线核心节点
   - 电机驱动节点
   - 长按遥控节点
   - 摇杆节点
   - Web 页面和 dashboard

旧服务 `line-follow-remote.service`、`line-follow-stack.service`、`line-follow-web.service` 只作为迁移来源保留说明，不应再和联合服务同时运行。

另外仓库里提供了脚本版监控工具：

```bash
python3 /userdata/dev_ws/src/originbot/Line_follow/tools/monitor_runtime.py
```

持续刷新模式：

```bash
python3 /userdata/dev_ws/src/originbot/Line_follow/tools/monitor_runtime.py --watch
```

## 1. 先进入板端环境

```bash
cd /userdata/dev_ws
source /opt/ros/humble/setup.bash
source /userdata/dev_ws/install/setup.bash
```

## 2. 查看 systemd 服务状态

优先只看联合服务：

```bash
systemctl status line-follow-hybrid.service
systemctl is-active line-follow-hybrid.service
systemctl is-enabled line-follow-hybrid.service
```

确认旧服务没有再并行运行：

```bash
systemctl status line-follow-remote.service line-follow-stack.service line-follow-web.service
```

查看所有相关服务：

```bash
systemctl list-unit-files | grep line-follow
```

## 3. 查看服务日志

```bash
journalctl -u line-follow-hybrid.service -n 50 --no-pager
journalctl -u line-follow-hybrid.service -f
journalctl -u line-follow-hybrid.service -b --no-pager
```

## 4. 查看进程是否存在

```bash
ps -ef | grep -E "line_follow|joystick|remote_long_press|web_debug" | grep -v grep
```

关键进程：

```bash
pgrep -af line_follow_angle_node
pgrep -af line_follow_motor_model_node
pgrep -af motor_driver_control_node
pgrep -af remote_long_press_start_line_follow_node
pgrep -af joystick_drive_node
pgrep -af web_debug_dashboard_node
```

其中 `/line_follow_motor_model_node`、`/line_follow_angle_node`、`/motor_driver_control_node` 都应该只有一套。

## 5. 查看 ROS2 节点状态

```bash
ros2 node list
ros2 node list | sort | uniq -c | grep -E "line_follow|joystick|remote"
ros2 node info /line_follow_motor_model_node
```

如果这里看到两个 `/line_follow_motor_model_node`，说明旧服务或手工 launch 还没清干净。

## 6. 查看话题是否正常

```bash
ros2 topic list | grep -E "line_follow|joystick|motor_speed_cmd|hbmem_img|/image$"
ros2 topic hz /image
ros2 topic hz /line_follow/line_angle_deg
ros2 topic info /motor_speed_cmd -v
ros2 topic info /hbmem_img -v
```

关键话题：

```bash
ros2 topic echo /motor_speed_cmd
ros2 topic echo /joystick_override_active
ros2 topic echo /line_follow/line_detected
```

## 7. 查看参数是否生效

```bash
ros2 param list /line_follow_motor_model_node
ros2 param list /line_follow_angle_node
ros2 param get /line_follow_motor_model_node enabled
ros2 param get /line_follow_angle_node line_is_white
```

## 8. 常用组合命令

看联合服务状态和最近日志：

```bash
systemctl status line-follow-hybrid.service && \
journalctl -u line-follow-hybrid.service -n 30 --no-pager
```

看节点和关键话题：

```bash
ros2 node list | sort | uniq -c | grep -E "line_follow|joystick|remote" && \
ros2 topic list | grep -E "line_follow|joystick|motor_speed_cmd|hbmem_img|/image$"
```

检查是否误起两套模型节点：

```bash
ros2 node list | grep line_follow_motor_model_node | wc -l
```

## 9. watch 持续监控

```bash
watch -n 1 "systemctl status line-follow-hybrid.service --no-pager"
watch -n 1 \"source /opt/ros/humble/setup.bash && source /userdata/dev_ws/install/setup.bash && ros2 node list | sort | uniq -c | grep -E 'line_follow|joystick|remote'\"
watch -n 1 \"ps -ef | grep -E 'line_follow|joystick|remote_long_press|web_debug' | grep -v grep\"
```
